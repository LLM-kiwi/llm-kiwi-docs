This page covers patterns and practices that will help you build better, more reliable applications with LLM.kiwi.

## Prompt engineering

The way you write your prompts has a huge impact on response quality.

### Be specific

Instead of:

<Note>
  Too vague
</Note>

```json
{"role": "user", "content": "Tell me about cats."}
```

Do this:

<Tip>
  Specific and clear
</Tip>

```json
{"role": "user", "content": "List 5 interesting facts about domestic cats, each with a one-sentence explanation."}
```

### Use system messages effectively

<AccordionGroup>
  <Accordion title="Role-playing">
    ```json
    {"role": "system", "content": "You are a senior software engineer. Explain concepts clearly with code examples."}
    ```
  </Accordion>

  <Accordion title="Format control">
    ```json
    {"role": "system", "content": "Respond only with valid JSON. No markdown, no explanations."}
    ```
  </Accordion>

  <Accordion title="Tone setting">
    ```json
    {"role": "system", "content": "You are a friendly teacher explaining to a beginner. Use simple words and analogies."}
    ```
  </Accordion>

  <Accordion title="Constraint setting">
    ```json
    {"role": "system", "content": "Answer in 3 sentences or less. Be concise."}
    ```
  </Accordion>
</AccordionGroup>

## Error handling

```python
import openai
from openai import RateLimitError, APIError, APIConnectionError
import time

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

def safe_chat_completion(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(
                model="auto",
                messages=messages,
                timeout=30,
            )
        except RateLimitError:
            if attempt < max_retries - 1:
                time.sleep(2 ** attempt)
            else:
                raise
        except APIConnectionError:
            if attempt < max_retries - 1:
                time.sleep(1)
            else:
                raise
        except APIError as e:
            print(f"API error: {e}")
            raise
```

## Token optimization

<Tip>
  1 token ≈ 0.75 words in English. A 10-word sentence is roughly 13 tokens.
</Tip>

**Reduce prompt tokens:** Keep system prompts short, remove old conversation history, use shorter variable names.

**Control response length:** Set `max_tokens` to cap the response.

## Security

<Warning>
  Never expose your API key in client-side code, browser apps, or public GitHub repos.
</Warning>

**Do:** Store keys in environment variables, rotate keys periodically. **Don't:** Hardcode keys, commit them to git, share in logs.
