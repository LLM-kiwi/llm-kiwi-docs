All errors return a JSON response with an `error` object.

## Error format

```json
{
  "error": {
    "message": "Description of what went wrong",
    "type": "error_category",
    "code": "error_code"
  }
}
```

## 400 — Bad Request

| Code | Cause | Fix |
| --- | --- | --- |
| Missing model | No `model` field | Add `"model": "auto"` |
| Missing messages | No `messages` array | Add a `messages` array |
| Invalid model | Unknown model name | Use `"auto"` or `"hrllm"` |
| Invalid role | Bad role value | Use `"system"`, `"user"`, or `"assistant"` |

## 401 — Unauthorized

| Code | Cause | Fix |
| --- | --- | --- |
| `invalid_api_key` | Wrong key | Check key in [dashboard](https://llm.kiwi/dashboard) |
| `missing_api_key` | No auth header | Add `Authorization: Bearer sk_kiwi_...` |

## 429 — Rate Limited

| Cause | Fix |
| --- | --- |
| Too many requests | Wait and retry with backoff |

**Retry with exponential backoff:**

```python
import time
from openai import RateLimitError

def make_request(client, messages, max_retries=5):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(model="auto", messages=messages)
        except RateLimitError:
            if attempt == max_retries - 1:
                raise
            time.sleep(2 ** attempt)
```

## 500 — Server Error

Temporary issue on our end. Retry after a few seconds.

## Debugging checklist

1. Is your key correct? — `curl "https://api.llm.kiwi/v1/models" -H "Authorization: Bearer sk_kiwi_..."`
2. Is your JSON valid? — Use jsonlint.com
3. Is your base URL correct? — Must be `https://api.llm.kiwi/v1`
