## General

### Is LLM.kiwi really free?

Yes. No credit card, no trial period. Create API keys and make requests immediately.

### Do I need to install anything?

Not for cURL. For Python or JavaScript, install the OpenAI SDK: `pip install openai` or `npm install openai`.

### Do I need an AI background?

Not at all. If you can send an HTTP request, you can use LLM.kiwi.

### What's the catch?

No catch. Free for learning, prototyping, and small-scale projects.

## API keys

### How do I get an API key?

Sign in at [llm.kiwi/login](https://llm.kiwi/login) with Google or GitHub, then go to the [dashboard](https://llm.kiwi/dashboard) and click **Create Key**.

### What if someone steals my key?

Revoke it immediately in the [dashboard](https://llm.kiwi/dashboard) and create a new one.

### Can I have multiple keys?

Yes. Use separate keys for development, staging, and production.

## Technical

### Why am I getting a 401 error?

Missing or invalid API key. Check the header format: `Authorization: Bearer sk_kiwi_...`

### Why am I getting a 429 error?

Rate limit exceeded. Wait a few seconds and retry.

### Can I stream responses?

Yes. Set `"stream": true`. See [Code Examples](/examples) for implementations.

### Is there a web interface?

Yes — visit [chat.llm.kiwi](https://chat.llm.kiwi).
