LLM.kiwi gives you free access to AI models through an OpenAI-compatible API. Point your existing tools at our endpoint and start making requests in seconds.

**Base URL:** `https://api.llm.kiwi/v1`

**Endpoint:** `POST /v1/chat/completions`

**Auth:** `Authorization: Bearer sk_kiwi_...`

## Try it right now

```bash
curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Say hello!"}]
  }'
```
