LLM.kiwi provides a free, OpenAI-compatible API endpoint for chat completions. Use your existing OpenAI SDKs and tools — just point them at our base URL.

**Base URL:** `https://api.llm.kiwi/v1`

**Endpoint:** `POST /v1/chat/completions`

**Auth:** `Authorization: Bearer sk_kiwi_...`

## What you get

- **Free access** — no credit card required
- **OpenAI-compatible** — works with any OpenAI SDK (Python, Node, Go, etc.)
- **Smart routing** — use `auto` and the best available model is selected for you
- **Croatian model** — use `hrllm` for dedicated Croatian-language generation
- **Key management** — create, label, and revoke API keys from the dashboard

## Quick start

<Steps>
  <Step title="Create an account">
    Sign in with Google or GitHub at [llm.kiwi](https://llm.kiwi/login).
  </Step>
  <Step title="Get your API key">
    Open the [dashboard](https://llm.kiwi/dashboard), go to **API Keys**, and create a key starting with `sk_kiwi_...`
  </Step>
  <Step title="Send your first request">
    Point any OpenAI-compatible client at `https://api.llm.kiwi/v1`, set `model` to `auto`, and go.
  </Step>
</Steps>
