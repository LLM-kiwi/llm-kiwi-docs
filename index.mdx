## What is LLM.kiwi?

LLM.kiwi is a **free API** that gives you access to AI language models. If you've ever used ChatGPT, this is the same technology — but you control it from your own code.

**The short version:**
1. Get a free API key at [llm.kiwi](https://llm.kiwi/login)
2. Send a message to `https://api.llm.kiwi/v1/chat/completions`
3. Get an AI response back

That's it. No servers to run. No models to download. No credit card.

## Try it now

Paste this into your terminal (replace `YOUR_API_KEY` with your real key):

```bash
curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Say hello!"}]
  }'
```

You should get a JSON response with the AI's reply. If you see an error, check [Troubleshooting](/troubleshooting).

## I'm brand new to APIs

No problem. Here's the 30-second explanation:

An **API** is just a way for your code to talk to a service over the internet. You send a request (like a text message), and you get a response back.

With LLM.kiwi:
- **You write code** that sends a message like `"Tell me a joke"`
- **Our API** receives it, runs it through an AI model, and sends back the joke
- **You display** the response in your app

No AI expertise needed. If you can send an HTTP request, you can use LLM.kiwi.
