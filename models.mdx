LLM.kiwi offers two models. In most cases, you should use `auto`.

## Model overview

<Tabs>
  <Tab title="auto">
    **Recommended for most use cases.**

    `auto` automatically routes your request to the best available model. As new models are added, your integration stays current without any code changes.

    ```json
    { "model": "auto" }
    ```

    **When to use it:**
    - General-purpose chat and Q&A
    - Prototyping and testing
    - Any situation where you want the best available model
    - You don't need a specific model behavior

    **What happens under the hood:**
    When you send `model: "auto"`, the LLM.kiwi gateway selects the current best model based on availability, performance, and your request type. This means the underlying model might change over time — but your code stays the same.
  </Tab>
  <Tab title="hrllm">
    **Dedicated Croatian-language model.**

    `hrllm` is optimized specifically for Croatian text generation. Pin this when your application requires consistent Croatian output.

    ```json
    { "model": "hrllm" }
    ```

    **When to use it:**
    - Croatian-language chatbots
    - Translating to/from Croatian
    - Generating Croatian text content
    - Any workflow where Croatian language is required

    **When NOT to use it:**
    - English-only applications (use `auto` instead)
    - When you're unsure (use `auto` instead)
  </Tab>
</Tabs>

## Comparison

| Feature | `auto` | `hrllm` |
|---------|--------|---------|
| Languages | All | Croatian-focused |
| Model selection | Automatic | Fixed |
| Updates automatically | Yes | No |
| Best for | General use | Croatian-specific tasks |

## How `auto` routing works

1. You send a request with `model: "auto"`
2. The gateway evaluates available models
3. The best match is selected based on your request
4. The response is returned with the actual model name in the `model` field

You can check which model was used by looking at the `model` field in the response:

```json
{
  "model": "auto",
  "choices": [...]
}
```

## Usage examples

**English (use `auto`):**

```bash
curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
  -H "Authorization: Bearer sk_kiwi_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Explain quantum computing"}]
  }'
```

**Croatian (use `hrllm`):**

```bash
curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
  -H "Authorization: Bearer sk_kiwi_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "hrllm",
    "messages": [{"role": "user", "content": "Objasni kvantno računarstvo"}]
  }'
```

<Note>
  If you're unsure which model to use, start with `auto`. You can always switch to `hrllm` later.
</Note>
