This guide takes you from zero to a working API call. If you've never used an API before, read [Concepts](/concepts) first.

## What you need

- A browser (to create your account)
- An internet connection
- A terminal or code editor

No credit card. No Docker. No special software.

## Get your API key

<Steps>
  <Step title="Sign in" icon="sign-in">
    Go to [llm.kiwi/login](https://llm.kiwi/login) and sign in with **Google** or **GitHub**.
  </Step>
  <Step title="Open the dashboard" icon="gauge-high">
    Go to [llm.kiwi/dashboard](https://llm.kiwi/dashboard).
  </Step>
  <Step title="Create an API key" icon="key">
    Navigate to **API Keys** and click **Create Key**. Copy the key that starts with `sk_kiwi_...`.

    <Warning>
      Save your key somewhere safe. You won't be able to see it again after closing the dialog.
    </Warning>
  </Step>
</Steps>

## Make your first request

Paste this into your terminal. Replace `sk_kiwi_...` with your real key.

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
      -H "Authorization: Bearer sk_kiwi_..." \
      -H "Content-Type: application/json" \
      -d '{
        "model": "auto",
        "messages": [{"role": "user", "content": "Hello!"}]
      }'
    ```
  </Tab>
  <Tab title="Python">
    ```bash
    pip install openai
    ```

    ```python
    import openai

    client = openai.OpenAI(
        base_url="https://api.llm.kiwi/v1",
        api_key="sk_kiwi_...",
    )

    response = client.chat.completions.create(
        model="auto",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.choices[0].message.content)
    ```
  </Tab>
  <Tab title="JavaScript">
    ```bash
    npm install openai
    ```

    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI({
        baseURL: "https://api.llm.kiwi/v1",
        apiKey: "sk_kiwi_...",
    });

    const response = await client.chat.completions.create({
        model: "auto",
        messages: [{ role: "user", content: "Hello!" }],
    });
    console.log(response.choices[0].message.content);
    ```
  </Tab>
</Tabs>

<Check>
  You should see a JSON response with `"choices"` containing the model's reply. If you see an error, check [Troubleshooting](/troubleshooting).
</Check>

## What just happened?

1. You sent a **POST request** to the chat completions endpoint
2. Your API key was included in the `Authorization` header
3. You specified `model: "auto"` so LLM.kiwi picked the best available model
4. You sent one **message** with role `user` and your text as the `content`
5. The response contains the AI's reply in `choices[0].message.content`

Read [Concepts](/concepts) to understand these building blocks in more detail.
