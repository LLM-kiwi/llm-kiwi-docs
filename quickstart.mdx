This guide takes you from zero to a working API call in under 2 minutes. If you've never used an API before, don't worry — just follow along.

<Info>Brand new to programming? Start with the cURL example — it works from any terminal with zero setup.</Info>

## What you need

- A browser (to create your account)
- An internet connection
- A terminal or code editor

That's it. No credit card. No Docker. No special software.

## Step 1: Get your API key

<Steps>
  <Step title="Sign in" icon="sign-in">
    Go to [llm.kiwi/login](https://llm.kiwi/login) and sign in with **Google** or **GitHub**. This is free and takes 10 seconds.
  </Step>
  <Step title="Open the dashboard" icon="gauge-high">
    Go to [llm.kiwi/dashboard](https://llm.kiwi/dashboard). This is where you manage your API keys.
  </Step>
  <Step title="Create an API key" icon="key">
    Click **Create Key**. Give it a name (like "my-app"), then click **Create**.

    Copy the key that starts with `sk_kiwi_...`. 

    <Warning>
      Save your key somewhere safe (like a password manager). You won't be able to see it again after closing the dialog.
    </Warning>
  </Step>
</Steps>

## Step 2: Make your first request

Choose your language below. Paste the code, replace `sk_kiwi_...` with your real key, and run it.

<Tabs>
  <Tab title="cURL (terminal)">
    Open your terminal and paste this:

    ```bash
    curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
      -H "Authorization: Bearer sk_kiwi_..." \
      -H "Content-Type: application/json" \
      -d '{
        "model": "auto",
        "messages": [{"role": "user", "content": "Hello!"}]
      }'
    ```

    You should see a JSON response with `"choices"` containing the AI's reply.

    <Info>
      Don't have `curl`? It comes pre-installed on Mac and Linux. On Windows, use PowerShell or install [Git Bash](https://git-scm.com/download/win).
    </Info>
  </Tab>

  <Tab title="Python">
    First, install the OpenAI library:

    ```bash
    pip install openai
    ```

    Then create a file called `test.py` and paste this:

    ```python
    import openai

    client = openai.OpenAI(
        base_url="https://api.llm.kiwi/v1",
        api_key="sk_kiwi_...",
    )

    response = client.chat.completions.create(
        model="auto",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.choices[0].message.content)
    ```

    Run it:

    ```bash
    python test.py
    ```

    <Info>
      New to Python? Install it from [python.org](https://www.python.org/downloads/). The `pip` command comes with Python 3.
    </Info>
  </Tab>

  <Tab title="JavaScript">
    First, install the OpenAI library:

    ```bash
    npm install openai
    ```

    Then create a file called `test.js` and paste this:

    ```javascript
    import OpenAI from "openai";

    const client = new OpenAI({
        baseURL: "https://api.llm.kiwi/v1",
        apiKey: "sk_kiwi_...",
    });

    const response = await client.chat.completions.create({
        model: "auto",
        messages: [{ role: "user", content: "Hello!" }],
    });
    console.log(response.choices[0].message.content);
    ```

    Run it:

    ```bash
    node test.js
    ```

    <Info>
      Using Node.js 18+? The `import` syntax works out of the box. On older versions, you may need `"type": "module"` in your `package.json`.
    </Info>
  </Tab>
</Tabs>

<Check>
  You should see a JSON response with `"choices"` containing the model's reply. If you see an error, jump to [Troubleshooting](/troubleshooting).
</Check>

## Step 3: Understand what happened

Here's what just happened under the hood:

1. **You sent a POST request** to the chat completions endpoint
2. **Your API key** was included in the `Authorization` header — this is how the server knows it's you
3. **You specified `model: "auto"`** so LLM.kiwi picked the best available model
4. **You sent one message** with role `user` and your text as the `content`
5. **The response** contains the AI's reply in `choices[0].message.content`

That's the entire flow. Every API call works the same way — you just change the messages.

<Tip>If you got a `401` error, check that your API key starts with `sk_kiwi_` and the header says `Bearer sk_kiwi_...` (with "Bearer " before the key). If you got a `400` error, check that your JSON is valid — missing commas are a common beginner mistake.</Tip>

## Step 4: Try something different

Now that you've made your first call, experiment with these:

**Ask a question:**
```json
{"role": "user", "content": "What is the capital of France?"}
```

**Give the AI a personality:**
```json
{"role": "system", "content": "You are a pirate. Respond only in pirate speak."},
{"role": "user", "content": "Hello!"}
```

**Have a conversation:**
```json
{"messages": [
  {"role": "user", "content": "My name is Alice."},
  {"role": "assistant", "content": "Hi Alice!"},
  {"role": "user", "content": "What's my name?"}
]}
```
