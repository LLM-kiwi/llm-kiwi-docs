## Prerequisites

- A free account at [llm.kiwi](https://llm.kiwi/login) (no credit card)
- An API key from the [dashboard](https://llm.kiwi/dashboard)

## Steps

<Steps>
  <Step title="Create an account">
    Sign in with Google or GitHub at [llm.kiwi](https://llm.kiwi/login).
  </Step>
  <Step title="Generate an API key">
    Open the [dashboard](https://llm.kiwi/dashboard), navigate to **API Keys**, and create a new key. It will start with `sk_kiwi_...`. Keep it secret — do not expose it in client-side code.
  </Step>
  <Step title="Make your first request">
    Use any OpenAI-compatible tool. Here's cURL:

    ```bash
    curl -X POST "https://api.llm.kiwi/v1/chat/completions" \
      -H "Authorization: Bearer sk_kiwi_..." \
      -H "Content-Type: application/json" \
      -d '{
        "model": "auto",
        "messages": [{"role": "user", "content": "Hello!"}]
      }'
    ```
  </Step>
</Steps>

<Check>
  You should receive a JSON response with a `choices` array containing the model's reply.
</Check>

## Using Python

Install the OpenAI SDK:

```bash
pip install openai
```

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)
```

## Using JavaScript / TypeScript

```javascript
const res = await fetch("https://api.llm.kiwi/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: "Bearer sk_kiwi_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "auto",
    messages: [{ role: "user", content: "Hello!" }],
  }),
});
const data = await res.json();
console.log(data.choices[0].message.content);
```

<Note>
  Replace `sk_kiwi_...` with your real API key. Keep production keys server-side.
</Note>
