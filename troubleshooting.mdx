## Common errors

### 401 Unauthorized

**You see:** `Invalid API key` or `Unauthorized`

**Causes:**
- Missing `Authorization` header
- API key is misspelled or truncated
- Key was revoked in the dashboard

**Fix:**
1. Check your header format: `Authorization: Bearer sk_kiwi_...` (note the `Bearer ` prefix)
2. Copy your key again from the [dashboard](https://llm.kiwi/dashboard)
3. If still failing, create a new key

---

### 429 Rate Limited

**You see:** `Rate limit exceeded` or `Too many requests`

**Causes:**
- Sending too many requests in a short time

**Fix:**
1. Wait a few seconds and retry
2. Add a delay between requests in your code
3. Consider upgrading to [Pro](https://llm.kiwi/pricing) for higher limits

---

### 400 Bad Request

**You see:** `Invalid request` or `Missing required field`

**Causes:**
- Missing `model` or `messages` field
- Malformed JSON body
- `messages` is not an array

**Fix:**
1. Make sure your JSON is valid (use [jsonlint.com](https://jsonlint.com) to check)
2. Ensure `model` is set to `"auto"` or `"hrllm"`
3. Ensure `messages` is an array of objects with `role` and `content`

**Correct format:**

```json
{
  "model": "auto",
  "messages": [
    { "role": "user", "content": "Hello!" }
  ]
}
```

---

### Empty or null response

**You see:** `content` is `null` or the response has no text.

**Causes:**
- The model's `finish_reason` might be `"length"` (hit token limit)

**Fix:**
1. Increase `max_tokens` in your request
2. Shorten your input messages

---

### Connection refused / timeout

**You see:** `ECONNREFUSED` or request times out.

**Causes:**
- Wrong base URL
- Network/firewall issues

**Fix:**
1. Make sure you're using `https://api.llm.kiwi/v1` (not `http`)
2. Check that your network allows HTTPS traffic
3. Try again — it might be a temporary issue

---

## Debugging tips

### Check your request

Use `curl` to test your request manually:

```bash
curl -v -X POST "https://api.llm.kiwi/v1/chat/completions" \
  -H "Authorization: Bearer sk_kiwi_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

The `-v` flag shows detailed request/response headers.

### Verify your key

List available models to confirm your key works:

```bash
curl "https://api.llm.kiwi/v1/models" \
  -H "Authorization: Bearer sk_kiwi_..."
```

If this returns a list of models, your key is valid.

### Check the response

Look at the full JSON response. The `error` object (if present) tells you exactly what went wrong.
