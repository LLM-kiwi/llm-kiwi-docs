LLM.kiwi gives you a free, OpenAI-compatible API. Here are practical things you can build — with code to get you started.

## Chatbots

Build a conversational bot for your website, app, or Discord server.

<CodeGroup>
```python Python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

# Keep conversation history
messages = [
    {"role": "system", "content": "You are a friendly customer support bot for a coffee shop."},
]

def chat(user_input):
    messages.append({"role": "user", "content": user_input})
    response = client.chat.completions.create(
        model="auto",
        messages=messages,
    )
    reply = response.choices[0].message.content
    messages.append({"role": "assistant", "content": reply})
    return reply

# Test it
print(chat("What are your hours?"))
print(chat("Do you have oat milk?"))
```

```javascript JavaScript
import OpenAI from "openai";

const client = new OpenAI({
    baseURL: "https://api.llm.kiwi/v1",
    apiKey: "sk_kiwi_...",
});

const messages = [
    { role: "system", content: "You are a friendly customer support bot for a coffee shop." },
];

async function chat(userInput) {
    messages.push({ role: "user", content: userInput });
    const response = await client.chat.completions.create({
        model: "auto",
        messages,
    });
    const reply = response.choices[0].message.content;
    messages.push({ role: "assistant", content: reply });
    return reply;
}

console.log(await chat("What are your hours?"));
```
</CodeGroup>

## Content generation

Generate blog posts, product descriptions, social media captions, or emails.

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

response = client.chat.completions.create(
    model="auto",
    messages=[
        {"role": "system", "content": "You are a marketing copywriter. Write concise, engaging product descriptions."},
        {"role": "user", "content": "Write a product description for wireless noise-cancelling headphones. Max 50 words."},
    ],
)
print(response.choices[0].message.content)
```

## Translation

Translate text between languages, including Croatian with the `hrllm` model.

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

# English to Croatian
response = client.chat.completions.create(
    model="hrllm",
    messages=[
        {"role": "system", "content": "Translate the user's text to Croatian. Output only the translation."},
        {"role": "user", "content": "How are you today?"},
    ],
)
print(response.choices[0].message.content)
```

## Summarization

Summarize long articles, meeting notes, or documents.

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

long_text = """
[Paste a long article, meeting transcript, or document here]
"""

response = client.chat.completions.create(
    model="auto",
    messages=[
        {"role": "system", "content": "Summarize the following text in 3 bullet points. Be concise."},
        {"role": "user", "content": long_text},
    ],
)
print(response.choices[0].message.content)
```

## Q&A over documents

Answer questions based on your own content. Feed the document as context and ask a question.

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

document = """
Our return policy allows returns within 30 days of purchase.
Items must be unused and in original packaging.
Refunds are processed within 5-7 business days.
"""

response = client.chat.completions.create(
    model="auto",
    messages=[
        {"role": "system", "content": "Answer the user's question using ONLY the provided document. If the answer isn't in the document, say so."},
        {"role": "user", "content": f"Document:\n{document}\n\nQuestion: How many days do I have to return an item?"},
    ],
)
print(response.choices[0].message.content)
```

## Streaming responses

For real-time UIs, stream tokens as they're generated instead of waiting for the full response.

```python
import openai

client = openai.OpenAI(
    base_url="https://api.llm.kiwi/v1",
    api_key="sk_kiwi_...",
)

stream = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Write a short poem about the ocean."}],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()  # newline
```
